# Ecommerce Application built with React Native and Expo.

## Tech Stack

- [Expo](https://expo.dev) - React Native development platform
- [Expo Router](https://docs.expo.dev/router/introduction) - file-based router 
- [NativeWind](https://www.nativewind.dev/) - For styling
- [Async Storage](https://react-native-async-storage.github.io/async-storage/) - Data storage system for React Native.
- [Context Api](https://react.dev/reference/react/createContext) - Store Data at top level.

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npx expo start
   ```

3. Open in iOS Simulator or Android Emulator:
   - Press `i` for iOS
   - Press `a` for Android
